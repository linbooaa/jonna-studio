# Joann Studio

台北市中正區舞蹈工作室介紹網站。單頁靜態網站，使用 GitHub Pages 託管。

## 內容
- 品牌故事與教室環境
- 三大課程：舞蹈啦啦隊、鋼管、地面課程
- 完整月課表
- 地址、交通、報名資訊

## 本機預覽
直接用瀏覽器開啟 `joann-studio.html` 即可，或執行：

```
python -m http.server 8000
```

再開啟 http://localhost:8000/joann-studio.html

## 更新內容
- 文字與課表：編輯 `joann-studio.html`
- 照片：替換 `images/` 資料夾內對應檔案（保持相同檔名）
